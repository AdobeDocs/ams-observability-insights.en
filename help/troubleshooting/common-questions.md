# Troubleshooting and FAQ {#troubleshooting-and-faq}

This page provides common starting points for users who are unsure where to begin. It also establishes a place to grow troubleshooting content as product-specific guidance becomes available.

## Common questions {#common-questions}

### I cannot access Synoptryx

Start with [Access and account management](../get-started/access-and-accounts.md). If provisioning is incomplete or outdated, contact your Customer Success Engineer (CSE).

### I do not know whether the issue is application or infrastructure related

Start with [Investigate application issues](../use-cases/investigate-application-issues.md), then compare what you see with [Investigate infrastructure issues](../use-cases/investigate-infrastructure-issues.md).

### I need to understand a specific graph or metric

Use the reference pages:

- [APM dashboard reference](../reference/apm-dashboard-reference.md)
- [Infrastructure dashboard reference](../reference/infrastructure-dashboard-reference.md)

### I need to know what data is actually collected

See [Coverage, environments, and data retention](../get-started/coverage-and-data.md) and [Metrics, coverage, and retention](../reference/metrics-and-retention.md).
